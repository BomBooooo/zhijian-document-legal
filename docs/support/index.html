SUPPORT · PUBLIC INTAKE

支持中心

获取安装、文档流程和错误诊断帮助。该支持渠道由独立发布者维护，不是学校官方服务。

不要上传文档。 GitHub Issues 是公开页面。请勿粘贴或上传论文、 DOCX/PDF、截图中的姓名学号、证件、联系方式或完整日志。

提交前准备

  1. 记录 Zhijian Document 版本和 Windows 版本；
  2. 使用不含真实内容的新建空白测试文档复现问题；
  3. 记录界面显示的稳定错误码；
  4. 删除文件路径、用户名、学校名称和其他个人信息。

创建公开支持请求

可以报告的内容

  • Microsoft Store 安装或更新问题；
  • 本地 DOCX 导入、编辑、保存、恢复或 PDF 导出问题；
  • 无障碍、界面流程或翻译问题；
  • 隐私、安全或公开支持内容删除请求。

响应边界

支持请求会按风险和可复现性排序处理，不承诺固定响应时限。数据丢失、错误覆盖原始输入、 未知 OOXML 丢失或安全问题将优先处理。支持人员不会要求用户提供论文原文或账户密码。

安全报告

请不要在公开 Issue 中披露可被利用的安全细节。先创建仅含“请求私密安全联系渠道” 以及软件版本的公开请求，不要包含漏洞细节或样本；维护者将提供后续安全交流方式。
