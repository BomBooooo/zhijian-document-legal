PRIVACY POLICY · VERSION 1.0

隐私政策

生效日期：2026 年 8 月 14 日

1. 适用范围与身份说明

本政策适用于 Zhijian Document Windows 桌面应用。该软件由独立发布者提供， 面向个人学生使用，不隶属于、不代表且未获得任何学校、学院或教育机构的官方背书。

2. 本地优先处理

应用的基础文档导入、编辑、排版、保存与导出在用户设备本地完成。 应用不会把论文、批注、模板内容或导出的 DOCX/PDF 上传到发布者服务器。

  • 无需注册账户；
  • 不提供云同步；
  • 不嵌入广告；
  • 不收集应用内文档内容、编辑历史或文件路径；
  • 核心排版功能不依赖 AI 或远程服务。

3. AI 与联网功能

当前面向 Microsoft Store 的基础版本不会在未取得用户明确授权时发送文档内容。 如果未来增加可选 AI 或远程能力，将在发送前单独说明接收方、数据范围和目的， 并要求用户主动选择；拒绝不会影响基础本地排版能力。

4. 第三方平台

Microsoft Store、Windows、GitHub 及本站托管平台可能依据各自政策处理下载、 更新、安全、崩溃或支持交互所产生的数据，这些处理不由 Zhijian Document 应用控制。 请查阅对应平台的隐私声明。

5. 支持请求

支持入口使用公开的 GitHub Issues。提交者自行决定公开的信息。请勿提交论文正文、 DOCX/PDF、学生证件、姓名、学号、联系方式、日志中的本地路径或其他个人信息。 仅需提供应用版本、Windows 版本、可公开的复现步骤和稳定错误码。

6. 保存、删除与安全

应用不会为发布者建立文档云端副本。本地文件的保存与删除由用户和 Windows 控制。 GitHub 支持请求的公开内容及平台日志由 GitHub 按其政策处理；如误发敏感信息， 请立即在支持页面发起删除请求，并同时使用 GitHub 提供的编辑或删除能力。

7. 儿童与教育场景

应用不要求提供年龄或学校身份，也不基于这些信息进行画像。 未成年人应在监护人和所在地区适用规则允许的范围内使用软件。

8. 政策变更与联系

政策发生实质变化时，将更新版本号和生效日期。隐私、安全或删除请求请通过支持中心提交。不要在请求中附加文档或个人信息。

English summary. Core document processing is local. The app does not require an account, upload documents to the publisher, provide cloud sync, or use document content for advertising. Optional network or AI features require explicit user authorization. Do not include document content or personal data in public support requests.
