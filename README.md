# Zhijian Document legal and support site

Public, read-only privacy and support information for Zhijian Document.

- Routes: `/`, `/privacy`, and `/support`
- No accounts, forms, document uploads, analytics, D1, or R2 storage
- Support intake is a separate public GitHub Issues repository with a privacy-safe issue template
- Canonical hostname: `legal.zhijianai.top`
- Static public host: GitHub Pages from the `docs/` directory on `main`
- The export strips runtime scripts and emits no forms, uploads, analytics, or data storage
